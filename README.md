# Roan Villaluz Portfolio

A responsive portfolio built with React and Vite to introduce my work in web and mobile application development.

## What's included

- About and contact sections
- Featured university projects
- Skills, education, seminars, and workshops
- Responsive layouts for mobile and desktop

## Built with

- React
- Vite
- CSS

## Run locally

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```
