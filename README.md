# Roan Villaluz Portfolio

A responsive portfolio built with React and Vite to showcase my projects, education, skills, and experience as an Information Technology student.

## What's included

- About and contact sections
- Project detail pages with screenshots and technology lists
- Skills, education, seminars, and workshops
- Responsive layouts for mobile and desktop

Project detail pages are available at `/#/projects/biyahero` and `/#/projects/degraded`.

## Built with

- React
- Vite
- CSS

## Run locally

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

Preview the production build locally with:

```sh
npm run preview
```
